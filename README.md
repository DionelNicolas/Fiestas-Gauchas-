# Fiestas gauchas 🇦🇷 — versión web instalable

## Qué incluye
- Diseño adaptable a celulares.
- Búsqueda por nombre, localidad y tipo.
- Filtros para domas, bailes y fiestas de campo.
- Detalle de evento.
- Guardado local de favoritos.
- Manifiesto PWA y service worker para instalación/uso básico sin conexión.

## Publicación gratuita de prueba con GitHub Pages
1. Crear un repositorio público llamado `fiestas-gauchas`.
2. Subir el contenido de esta carpeta (index.html, styles.css, app.js, manifest.webmanifest, sw.js, icons/).
3. En Settings > Pages, elegir Deploy from a branch, branch `main`, folder `/ (root)`.
4. Esperar a que GitHub Pages publique el sitio.

## Limitaciones de esta versión
Los eventos son datos de demostración. Los favoritos se guardan solo en el dispositivo. Todavía no hay cuentas, base de datos compartida, publicaciones de organizadores, mapa ni notificaciones push. No presentar los eventos de ejemplo como eventos reales.
